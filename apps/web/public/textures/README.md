Wood textures for the frame mockups (`FrameMockup`).

Grain from Poly Haven veneers (CC0, https://polyhaven.com): `black_walnut_veneer_01` (walnut),
`oak_veneer_01` (oak) and `ash_veneer` (natural), greyscaled and recoloured with a dark→light
gradient per wood, 512×512, grain running along the moulding (`-h` horizontal, `-v` vertical).
